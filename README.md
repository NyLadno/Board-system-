# Board

Бесконечная доска в духе Miro для macOS 12 (Monterey) и новее. Главная цель: перо графического планшета должно рисовать без ощущения вязкости, то есть линия идёт точно за кончиком пера.

Приложение работает на Electron 38 (Chromium 140), который официально поддерживает macOS 12. Intel и Apple Silicon подходят одинаково. Chromium выбран осознанно: в нём есть события пера с давлением и наклоном, `getCoalescedEvents()` с полной частотой планшета и независимый от интерфейса рисующий конвейер. В WKWebView на Monterey этого нет.

## Запуск на Mac

Нужен Node.js 20 или новее.

```bash
git clone https://github.com/NyLadno/Board-system-.git
cd Board-system-
npm install
npm start
```

Готовый `.dmg` для установки собирается командой `npm run dist` (на Mac). Сборка не подписана, поэтому при первом запуске macOS попросит подтвердить: правый клик по приложению, «Открыть». Те же артефакты собирает GitHub Actions по тегу `v*` или вручную (workflow «Build macOS app»).

## Что умеет

Досок можно создавать сколько угодно. Каждая доска бесконечна: масштаб от 2% до 3200%, а положение на плоскости ничем не ограничено. Чтобы далёкие области не теряли точность (GPU считает координаты в float32, и на миллионах единиц линии начинают дрожать), приложение переносит начало координат вслед за камерой: содержимое и история сдвигаются, картинка не меняется, накопленный сдвиг хранится в файле доски. Проверено на расстоянии 100 миллионов единиц. Все доски лежат в `~/Library/Application Support/Board/boards`, автосохранение идёт через 0.7 с после правки и при выходе, перед каждой записью делается резервная копия `.bak`.

Шаблоны: при создании доски открывается галерея с превью (в клетку, канбан, ретроспектива, SWOT, матрица Эйзенхауэра, майнд-карта, блок-схема, брейншторм, план недели) и пустая доска. Вид доски задаётся для каждой доски отдельно (кнопка с палитрой в верхней панели): стиль фона (точки, сетка, клетка, чистый), цвет фона и цвет линий меняются независимо, есть сброс и девять готовых схем (бумага, мята, небо, роза, грифельная доска, графит, ночь, чертёж). На тёмном фоне чёрное перо, текст и соединители автоматически становятся светлыми, на светлом возвращаются обратно, а выбранные вручную цвета не меняются. Всё хранится в файле доски, цвет фона попадает в экспорт. Новый шаблон это одна функция в `src/templates.js`.

Инструменты: выбор, рука, перо с давлением, маркер, ластик (стирает штрих целиком, обратный конец пера включает его автоматически), стикеры с автоподбором размера шрифта, текст, десять фигур, соединители (прямые, под углом, кривые, стрелки) с привязкой к четырём портам фигуры, фреймы, изображения (вставка из буфера, перетаскивание файла, кнопка).

Работа с объектами: рамка выделения, изменение размера с сохранением пропорций по Shift, поворот с шагом 15°, группы, Alt и перетаскивание для копии, направляющие привязки, выравнивание и распределение, порядок слоёв, блокировка, копирование и вставка (в том числе между досками), неограниченная отмена и повтор. Содержимое фрейма двигается вместе с ним.

Навигация: два пальца на трекпаде двигают доску, щипок масштабирует, колесо мыши масштабирует, пробел включает руку, есть мини-карта (чёткая, с формой объектов: штрихи, фигуры, стикеры, коннекторы; клик или перетаскивание ведёт камеру, далёкие одиночные объекты не ужимают карту и показаны точками у края). Экспорт в PNG, SVG, PDF и файл доски `.board.json` (с картинками внутри), импорт файла доски. PDF в приложении векторный: текст остаётся текстом и копируется, страница равна размеру содержимого, при выделенных объектах экспортируется только выделенное (вне Electron включается запасной вариант с картинкой внутри PDF). Интерфейс на русском и английском, светлая и тёмная тема. Все горячие клавиши перечислены в настройках (⌘,).

## Работа только пером (планшет по USB)

У планшета нет колеса, щипка и двух пальцев, поэтому доска управляется одним пером. Боковая кнопка пера (любая из двух) двигает доску, пока вы её держите и ведёте пером, в любом инструменте. Масштаб меняется перетаскиванием: удерживайте клавишу Z или пробел вместе с ⌘/Ctrl и ведите пером вверх (приближение) или вниз (отдаление), точка под пером остаётся на месте. Клавиши на планшете (Express Keys) удобно привязать к этим сочетаниям, а также к V, H, P, E и ⌘Z. Кроме того, в левом нижнем углу есть ползунок масштаба, кнопки «+» и «−» и кнопка «показать всё». Обратный конец пера стирает. Горячие клавиши по буквам работают и на русской раскладке.

## Почему перо не вязнет

Ощущение вязкости почти всегда даёт одна из четырёх причин, и каждая здесь убрана отдельно.

1. Дрожание линии. Планшет и драйвер отдают координаты с шумом (часто целыми пикселями), а контур штриха чувствителен к направлению между соседними точками. Поэтому включён адаптивный фильтр One Euro: на медленных движениях он гасит шум, на быстрых почти не отстаёт (отставание порядка 2 пикселей на 500 пикселей в секунду, его компенсирует предсказание). Контур строится по касательной из окна в пять точек, а давление сглаживается отдельно. Сила фильтра настраивается (по умолчанию 35%), 0 выключает его целиком.
2. Перерисовка лишнего. Живой штрих рисуется на отдельных прозрачных холстах над сценой. Готовая часть замораживается порциями, на кадр перерисовывается только короткий хвост в небольшом прямоугольнике. На штрихе из 4000 точек кадр занимает порядка 1 мс. События пера обрабатываются сразу при поступлении (`pointerrawupdate`), без ожидания следующего кадра, и учитываются все отсчёты планшета (`getCoalescedEvents`).
3. Задержка конвейера. Кончик линии продлевается предсказанием на 14 мс вперёд (настраивается от 0 до 40). Предсказанный кончик рисуется отдельным коротким отрезком поверх настоящей линии и не влияет на её форму, иначе линия дрожала бы от кадра к кадру. Скорость берётся из окна не короче 14 мс, ускорение не используется, на малой скорости и на резких поворотах предсказания нет. Курсор-кружок размера кисти это системный курсор, у него нет собственной задержки.
4. Лаги при перемещении по доске. Сцена рисуется один раз в холст с запасом по краям окна, а жест только сдвигает или масштабирует этот готовый слой на уровне композитора. Полная перерисовка делается, когда запас кончился или зум успокоился. Точки, сетка и клетка рисуются в тот же холст (раньше это был CSS-фон, который перерисовывался на каждом кадре). Всё, что не относится к самому жесту (подписи, мини-карта, сохранение), выполняется один раз за кадр или после паузы.

Дополнительно: окно не троттлится в фоне, автосохранение откладывается, пока вы рисуете, миниатюры строятся только при выходе из доски.

Включите «Показывать диагностику отклика» в настройках, чтобы видеть FPS, стоимость кадра сцены и время от события пера до отрисовки.

Ограничение: измерения здесь делались в Chromium без GPU и с эмуляцией пера. Настоящее ощущение зависит от вашего планшета и драйвера, поэтому длину предсказания и сглаживание стоит подстроить на самом устройстве. Если линия «убегает» вперёд на изгибах, уменьшите предсказание, если чувствуется отставание, увеличьте.

## Разработка

```bash
npm run dev          # доска в обычном браузере на http://localhost:5173 (данные в IndexedDB)
npm test             # модульные тесты логики (Node)
npm run test:e2e     # сценарии в Chromium через Playwright, включая рисование «пером»
```

Структура:

```
main.js, preload.js        процесс Electron, меню, хранение файлов
src/app.js                 состояние, команды, сохранение
src/input.js               мышь, перо, касания, колесо, клавиши
src/render/                холсты, живые чернила, контуры штрихов, фигуры
src/tools/                 инструменты (перо, ластик, выбор, создание объектов)
src/core/                  сцена, камера, история, хранилище
src/ui/                    панели, список досок, настройки, редактор текста
test/                      модульные и e2e тесты
```

Приложение не требует сборки: это обычные ES-модули. Один и тот же код запускается и в Electron, и в браузере, поэтому интерфейс удобно проверять без установки.
